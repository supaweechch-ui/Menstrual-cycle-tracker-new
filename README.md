# ตัวช่วยติดตามรอบเดือน

ไฟล์ชุดนี้พร้อมสำหรับโฮสต์บน GitHub Pages เป็น PWA ที่ใช้งานออฟไลน์ได้จริง

## วิธีอัปขึ้น GitHub Pages

1. สร้าง repo ใหม่บน GitHub (public repo ใช้ Pages ได้ฟรี)
2. อัปโหลดไฟล์ทั้งหมดนี้ไว้ที่ root ของ repo:
   - `index.html`
   - `manifest.json`
   - `icon.svg`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-180.png`
   - `icon-512-maskable.png`
   - `sw.js`
3. เข้า Settings → Pages ของ repo → เลือก Branch เป็น `main` (หรือ branch ที่อัปไว้) โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ GitHub จะให้ลิงก์ประมาณ `https://<username>.github.io/<repo-name>/`
5. เปิดลิงก์นั้นบนมือถือ แล้วกด "เพิ่มไปยังหน้าจอหลัก" — คราวนี้จะติดตั้งเป็นแอพเต็มรูปแบบ พร้อมใช้งานได้แม้ไม่มีเน็ต (หลังเปิดออนไลน์ครั้งแรกไปแล้วอย่างน้อย 1 ครั้ง)

## หมายเหตุ

- ข้อมูลที่กรอก (วันที่ประจำเดือน, การตั้งค่า) เก็บอยู่ใน localStorage ของเบราว์เซอร์/อุปกรณ์นั้น ๆ ไม่ได้ sync ข้ามเครื่อง และไม่ได้ส่งขึ้น GitHub หรือเซิร์ฟเวอร์ใด ๆ
- ถ้าแก้ไข `index.html` ในอนาคต ให้เปลี่ยนเลข `CACHE_NAME` ใน `sw.js` ด้วย (เช่น `cycle-tracker-v2`) ไม่งั้นเครื่องที่เคยติดตั้งไว้จะยังเห็นไฟล์แคชเก่าอยู่
